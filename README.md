# HUB · Collection Store

Премиальный лендинг (главная страница) для интернет-магазина **HUB — Collection Store**:
коллекционные фигурки бойцов, официальный мерч UFC, спортивная экипировка.

## О проекте

Это статическая HTML / CSS / JS демо-страница, которая показывает визуальный язык бренда.
Ничего собирать не нужно — открывайте `index.html` или поднимайте любой статический сервер.

### Что внутри

- **Преloader** с пошаговой анимацией приветствия «Добро пожаловать в HUB», золотым шиммером логотипа и плавной шторкой.
- **Hero** с параллакс-фонами, светящимися пятнами, премиум-карточкой `Champion Series` и анимированной бегущей строкой.
- **Категории** в bento-сетке: фигурки, мерч UFC, экипировка, лимитированные дропы.
- **Витрина новинок** с фильтром по категориям, hover-tilt и SVG-иллюстрациями товаров.
- **Showcase бойцов** — карточки в стиле постера.
- **About** с features-листом, премиум-постером и счётчиками.
- **CTA / подписка** на закрытый клуб.
- **Футер** с соцсетями и ссылками.

### Технологии

- Чистый HTML5, CSS3 (Grid, custom properties, `clamp()`, `mix-blend-mode`, `backdrop-filter`).
- Vanilla JS: прелоадер, scroll-reveal через `IntersectionObserver`, 3D-tilt на курсор, кастомный курсор, фильтр товаров, плавный скролл, счётчики.
- Шрифты Google Fonts: Bebas Neue, Manrope, Playfair Display.
- Без зависимостей и сборщиков.

## Локальный запуск

```bash
# любой статический сервер, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000
```
